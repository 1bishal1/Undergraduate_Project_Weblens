**WebLens**
A Google Chrome Extension for Real-Time Frontend Website Analysis
1. Project Overview
WebLens is a planned Google Chrome extension for analysing and understanding the frontend structure of websites. The project aims to provide a simple and beginner-friendly way to inspect webpage elements and view useful frontend information without requiring users to navigate through complex browser developer tools.
The extension is intended to help developers, designers, students, and beginners understand how different elements of a website are structured and styled.
